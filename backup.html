💾 Backup Database

Esegui il backup completo del database Firebase e scarica i dati in formato JSON o CSV.

⚙️ Funzionalità:
  • Backup di tutte le collezioni (orders, orders_bar, orders_cucina, counters)
  • Esportazione in JSON (completo, con tutti i dettagli)
  • Esportazione in CSV (riepilogo ordini, compatibile con Excel)
  • Timestamp automatico nei nomi dei file
  • Log in tempo reale del processo
